# Shadow Realm - Text-based RPG Game

Welcome to **Shadow Realm**, a terminal-based RPG adventure game written in C! Explore a mysterious cave, make strategic choices, and face a dangerous dragon to claim ancient treasure.

---

##  Game Features
* **Interactive Choices:** Story-driven path selection that affects your health and outcome.
* **Player Stats:** Track your Health, Gold, and Attack Power in real-time.
* **Multiple Endings:** Victory, Game Over, or Secret Treasure Ending based on your stats and choices.

---

##  How to Run the Game

### Prerequisites
* A C compiler (like GCC) installed on your system.

### Compilation & Execution
1. **Download the code:** Download `main.c` from this repository.
2. **Compile:**
   ```bash
   gcc main.c -o shadow_realm
